## 高级排版阅读器

- 入口位于阅读区右上工具栏的 **aA 排版**。原生 `dialog#typography-panel.typography-popover` 提供弹簧开合、Esc、外部点击、关闭按钮及双击把手退出；关闭后恢复入口焦点。面板打开时屏蔽词典快捷键，避免误切词或清空查询。减少动态效果偏好使用淡入淡出。
- 字号覆盖 85% / 95% / 100% / 115% / 130%，首尾禁用对应按钮；词头、音标、释义、英文定义、例句、场景、构词与词源统一缩放。四种字族使用本地系统字体回退，不引入 CDN。高易读体额外增加字距和词距。
- 紧凑 / 标准 / 舒展分别采用 1.45 / 1.65 / 1.85 行高及 0.8 / 1 / 1.25 内边距系数，例句与构词卡片同步调整。
- 纸白沿用原生深浅主题；暖黄、素灰及 OLED 黑独立控制阅读背景、正文、例句和标签颜色，避免与全站主题混用导致低对比度。侧栏尺寸、列表字号和全站主题选择保持独立。
- 配置保存至 `open_lexicon_typography`，刷新/重新打开恢复；逐字段白名单校验，异常存储回落默认。恢复默认只重置排版，保留语言、收藏和主题；每次有效切换提供 8ms 反馈，存储或振动不可用时仍可在当前页使用。
- 新增 13 项自动检查涵盖入口中文和原生对话框结构、全部选项、字号边界、偏好恢复/重置、非法偏好、存储拒绝、动画中断、关闭方式、快捷键隔离及动态效果偏好。浏览器脚本另补实际字阶比例、密度、双色主题下三种纸色、刷新恢复与移动端面板边界检查；尚未运行通过，不计入 57 项通过数。

## 本轮可用结果

- 页面默认 A–Z；可选考纲核心顺序、多义词丰富度、Z–A。Worker 未传 sort 时保留原始顺序，rank 按 id 排序；有搜索文本时仍按精确、前缀、包含、近似拼写的相关性优先，各组内采用所选排序。多义词按实际义项数降序，同数按字母及 id 确定顺序。
- 页码输入支持 Enter 和跳转按钮，上一页/下一页按当前可见页操作。每页 50 词，全量 25,006 词共 501 页，末页 6 词。总页数随搜索和筛选计算，非法输入不发请求，越界夹到有效页；零结果禁用控件。
- 连续词流支持从任意页向下追加、向上补载，补载时保持现有行与滚动位置，方向键可跨两端相邻页。页码由视口顶部可见词行同步；新搜索、排序或筛选会重置分页，旧响应不能覆盖新结果。
- 初次打开 #available 或改变地址片段只指定详情与定位页，不写入搜索框、不添加单词过滤。初次搜索框为空，定位页仍属于完整词表，选中词高亮并 scrollIntoView。抽认的“在词典中细读”沿用同样机制。用户手动输入才改变文本查询；清空恢复当前其他筛选下的词流。
- 默认 340px 侧栏的“全部 + A–Z”采用 14+13 两行；缩窄至 240px 时采用三行以保证可读。考试和二级前缀自然折行，没有单行横向滚动条。收藏并入结果信息行，排序/词性采用紧凑下拉，保留 52px 词行。宽度拖拽、键盘调节和偏好保存沿用原实现。
- 固定顶栏的空间统一留在 workspace 外层，阅读区内部 toolbar 保持 sticky top:0，避免滚动后进入全站顶栏下方。词头 32px/700，中文释义 17px，英文定义 14.5px，译文 13px；例句和搭配紧跟各自义项。
- 移除要素一/二的独立大标题带，语义标识融合到首个义项的定义、场景容器；构词和词源保留小卡片标题。真实词条共 4 个 dimension，含要素一至四，无核心折叠。阅读区宽度至少 640px 时构词/词源 50%/50% 并排，窄屏单列。
- 双语/纯英切换、英美发音、义项速览、收藏、复制、深色主题、沉浸、抽认、离线能力保留。纯英隐藏中文学习正文并提升英文定义和例句字阶；中文构词/词源不虚构英文翻译。

## 在线入口与缓存

入口：[http://127.0.0.1:8765/#available](http://127.0.0.1:8765/#available)。本轮从现有 8765 服务读取 index.html、app.js、styles.css、sw.js，四项均 HTTP 200，逐字节与磁盘一致。刷新后加载新资源；HTTP 证据不等于视觉验收。

需要启动时，在根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory app/static
```

离线能力仍需首次联网取得页面与索引，词条按字母缓存；完整准备支持 27 分片下载、中断及恢复。发布时需包含被 Git 忽略的 app/static/data/。没有付费 API、外部 CDN 或后端检索请求。
