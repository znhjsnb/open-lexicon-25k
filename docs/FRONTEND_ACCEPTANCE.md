## 启动与部署

在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory app/static
```

打开 `http://127.0.0.1:8765/`。本次临时静态服务器使用 `http://127.0.0.1:8876/`，已实际请求页面、全部 JS/CSS 模块、Service Worker、索引及 a 分片，均返回 HTTP 200。HTTP 200 只证明资源可访问，不证明页面渲染与交互已通过。

运行时仅需 `app/static/` 中的 index.html、styles.css、app.js、worker.js、db.js、data.js、sw.js 和整个 data/。无构建依赖、外部字体、付费 API 或 CDN 请求；不调用 `/api/words` 或其他后端 API。可用 Python、Node 静态服务器，所有应用路径均相对当前部署目录解析。

GitHub Pages 应发布该目录的完整站点产物，**必须包含被 Git 忽略的 data/**。不能仅提交源码后假定线上也有数据。当前源数据已生成；缺失时使用现有 `python src/export_web_shards.py` 从已导出的 SQLite 重新生成。没有改动原始数据、导出器或 app/server.py，也没有执行公开部署。

## 已实现的行为

- Worker 非阻塞载入全量索引。精确匹配优先，其次前缀、子串；没有精确匹配且直接结果不足 50 时补充拼写容错，支持增删替换与相邻字符交换。中文搜索各义项摘要。查询合并考试、词性、收藏筛选，每次只传输最多 50 词，分页可覆盖全部词库。
- 内存保留最近 3 个字母分片，IndexedDB 按数据版本原子保存整个分片。并发读取同字母仅请求一次；失败可重试。存储被禁用、同步抛出 SecurityError、配额不足时仍允许当前页联网查词，不虚报离线成功。
- 默认浅色双栏工作台，系统字体和衬线词头；所有义项、英文定义、中文解释、原有例句与搭配、现代构词及词源始终平铺。支持深色主题、英美发音药丸、例句朗读、波形状态、收藏、Markdown / Anki TSV 复制。
- `/`、Ctrl/Cmd+K 聚焦搜索，Esc 清空；沉浸模式内先退出沉浸。上下键可在搜索框或词表中切词并跨页；Enter 阅读。处理中文输入法组合输入、查询版本与详情加载版本，防止旧响应覆盖新选择。
- 沉浸模式隐藏侧栏并放大排版。原生模态学习抽屉包含每日一词、按当前考试范围抽认、翻牌、再次复习、记住后打卡、连续学习天数；进度仅保存在本机。模态窗口使用原生焦点约束与 Esc，关闭后回到触发控件。
- 抽屉进入、翻牌、按钮按压及语音波形仅动画 transform / opacity，统一 `cubic-bezier(0.16, 1, 0.3, 1)`。按钮按下 scale(.98)，键盘切词不播放进场动画，尊重 reduced-motion。

## 离线范围与更新

首次访问必须通过 HTTP(S) 下载页面与索引；不能从 file:// 双击启动 Worker 应用。Service Worker 离线页面需要 HTTPS 或 localhost/127.0.0.1 安全来源。

默认按需保存查过的字母。左下角“准备离线词库”由用户主动触发全部 27 分片下载，可在当前分片完成后暂停，再次点击可继续利用已保存分片。索引为 6,704,398 字节（6.39 MiB），分片总计 47,098,101 字节（44.92 MiB）；未计浏览器存储额外开销。只有索引、离线页面及所有分片均保存成功才显示已备齐。

断网后可从 Cache Storage 恢复索引、从 IndexedDB 恢复已保存词条；未准备完整词库时，未缓存的字母会提示联网，提供重试。完整准备后全部词头均可本地查阅。浏览器清理站点数据或存储回收会丢失离线数据；朗读还依赖系统英语语音包，优先使用本地英语声音。

发布新数据时修改 data.js 的 DATA_VERSION；发布新页面外壳时更新 sw.js 的 SHELL_CACHE。普通在线刷新会重新检查页面资源；更新不会清除用户收藏与打卡。

## 数据兼容与代码自查

| Before | After | Why |
| --- | --- | --- |
| 标签值实际含引号和方括号 | 消费端 normalizeTags 后再匹配和显示 | CET4 / IELTS 等筛选须匹配实际标签，源文件保持原样 |
| `April` 等原始词头大小写与分片键不同 | 用小写键读取，保留原始词头展示 | 防止专有名词检索成功却无法打开 |
| API 列表与详情可能乱序覆盖 | 查询与选词分别使用递增版本号 | 快速输入和慢分片完成时保留最新选择 |
| 常规编辑距离扫描产生大量数组 | 有界对角带与复用缓冲区 | 控制容错检索开销，精确命中无需扫描容错候选 |
| 缓存故障可能阻断查词 | 内存降级、失败去重状态清理、坏索引移除 | 网络恢复后可以重试，不能将缓存失败当作离线成功 |
| 全量词表直接生成大量节点 | 每次仅渲染 50 个结果，可键盘跨页 | 保持 DOM 数量有界且所有词仍可访问 |

源分片每义项只有一组完整 sentence_en / sentence_zh，另有通常两组 collocation。界面如实展示“例句”和“场景搭配”，**没有补造第二句完整例句**。已有 `+ … → …` 构词公式会被提取强调，不能拆解的整词仍保留源说明，不伪造词根。
